# FishEye: A Fish Vision Software

## Description

Counts fish in an uploaded video and applies filters to make them easier to see by a human. 

## Setup instructions

### Developers

The program runs as a Flask app and requires the installation of Python 3.0 or higher. Once Python is installed, run 

`python app.py`

to start the app. You can then open the app in a browser using the indicated link. 

### End users

We will provide instructions to download the app to your device as soon as the app version is available. 

## Usage

This software is targeted towards aquatic researchers who can watch the video one time to review its output. Our software speeds up the enumeration process for an analyst. The intended usage is for a human to be watching the video to verify our program's findings.
